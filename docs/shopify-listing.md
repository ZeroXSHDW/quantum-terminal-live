## Fulfilment (digital delivery)

The paid product is the GitHub Release, already built:

```
https://github.com/ZeroXSHDW/quantum-terminal-live/releases/tag/v3.1.1
```

Choose one delivery path:

1. **Shopify "Digital Downloads" app (recommended)** — install the free
   [Digital Downloads](https://apps.shopify.com/digital-downloads) app, attach
   `Quantum-Terminal-Live-3.1.1.dmg`, and it auto-emails the download after payment.
2. **Manual** — set the product to "not shipped", and email the release URL after
   each order (or add it to the order confirmation note).

> Refresh the release after a future build with `make dmg` + `gh release create`.

## Quick note on the buy button

The web storefront and showcase page use a Stripe Payment Link placeholder
(`https://buy.stripe.com/REPLACE_ME`). If you sell through Shopify instead, swap
that URL for this product's Shopify checkout link in `docs/index.html` and
`docs/showcase.html`, then re-push — the hosted pages update automatically.
